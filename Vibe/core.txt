## STATUS NODE (OKTAGON)
================================================================

LOCKED    → Oktagon gelap + ikon gembok merah berdenyut
             Kondisi: Node sebelumnya belum selesai

ACTIVE    → Oktagon Electric Blue (#3498DB), animasi pulse/rotate
             Kondisi: Siap dimainkan

COMPLETED → Oktagon Neon Emerald (#2ECC71), aura hijau kuat
             Kondisi: Selesai dengan skor ≥ 60%

PERFECT   → Oktagon Emas berkilau + efek bintang
             Kondisi: Selesai dengan skor 100%


================================================================
## CHAPTER BOSS
================================================================

- Setiap akhir chapter ada 1 BOSS NODE.
- Boss berisi quiz campuran dari semua materi chapter tersebut.
- Harus lulus Boss untuk membuka Chapter berikutnya.
- Boss mengkonsumsi HEART seperti biasa.
- Skor minimum untuk lulus Boss: 70% (lebih tinggi dari node biasa).

## SISTEM HEART (NYAWA)
================================================================

Kapasitas Awal    : 5 ❤️ (langsung setelah daftar)
Berkurang         : -1 ❤️ setiap jawaban SALAH
Regenerasi Otomatis: +1 ❤️ setiap 1 JAM (cooldown timer)
Kapasitas Maksimum: 5 ❤️ (tidak bisa melebihi ini, kecuali ada event)
Habis?            : Quiz terhenti, modal "Out of Hearts" muncul

BONUS HEART:
- Jawab 5 soal berturut-turut BENAR → dapat +1 ❤️ bonus (max 5)

MODAL "OUT OF HEARTS":
- Tampilkan waktu cooldown hingga heart berikutnya
- Tombol "REFILL NOW"    → Gunakan 50 💎
- Tombol "WATCH AD"      → Dapat +1 ❤️ (mockup AdMob)
- Tombol "COME BACK LATER" → Tutup modal

## SISTEM DIAMOND (💎)
================================================================

Diamond adalah mata uang premium Axlingo.
Didapat dari: Menyelesaikan node, achievement, daily login, atau beli.

Digunakan untuk: Power-up di Shop, Refill Heart.

Top-up packages (via Midtrans):
- Starter Pack  : 100 💎   → Rp 15.000
- Popular Pack  : 300 💎   → Rp 35.000
- Best Value    : 700 💎   → Rp 70.000
- Mega Pack     : 1500 💎  → Rp 130.000

## LESSON OVERVIEW (MODAL SEBELUM MULAI NODE)
================================================================

Ketika user tap sebuah node ACTIVE, muncul modal preview:
- Judul pelajaran
- Thumbnail/ikon chapter
- Target: "Kamu akan belajar X kata slang baru"
- Estimasi waktu: ~3 menit
- Reward yang akan didapat: XP + 💎
- Cek ketersediaan heart (jika 0, tampilkan peringatan)
- Tombol "START MISSION" → Mulai quiz


================================================================
## STREAK SYSTEM
================================================================

- Streak bertambah +1 setiap hari user menyelesaikan minimal 1 node.
- Ditampilkan di Profile dan Topbar sebagai ikon api 🔥.
- Streak HILANG jika tidak belajar 1 hari penuh (kecuali Streak Freeze aktif).
- Milestone streak memberikan reward:
  - 3 hari  : +20 XP
  - 7 hari  : +50 XP, +10 💎
  - 30 hari : +200 XP, +50 💎 + Badge "Iron Will"
  - 100 hari: +500 XP, +100 💎 + Badge "Cyber Monk"
