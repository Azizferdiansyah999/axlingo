## FASE 3: CORE UI SHELL (THE INTERFACE)

**3.1 Global Visual Tokens & Shell (The Mood)**
- 3.1.1 Color Variables: Terapkan palet warna global:
  - Background: Deep Charcoal (#121212) - Gelap total.
  - Primary/Branding: Vivid Purple - Warna utama VibeLingo.
  - Interactive: Electric Blue (#3498DB) - Tombol, Hover, Link.
  - Success: Neon Emerald (#2ECC71) - Jawaban benar, Progress Bar penuh.
  - Typography: Off-white & Bold Sans-serif - Futuristik dan mudah dibaca.
- 3.1.2 The Glass Effect: Buat satu komponen CSS/Tailwind Class bernama `vibe-glass` yang memiliki: background-opacity: 0.1, backdrop-filter: blur(10px), border: 1px solid rgba(255,255,255,0.05), dan box-shadow: neon-purple.
- 3.1.3 Shell Shell Layout:
  - Sidebar Menu: Ikon vector minimalis. Saat menu aktif, ikon dan teksnya menyala warna Vivid Purple dengan efek glitch tipis (Framer Motion).
  - Topbar: Menampilkan Diamond Rank dengan ikon Diamond 3D yang bersinar.

**3.2 Modul 1: THE PATH (Learning Journey)**
- 3.2.1 Glowing Nodes: Node pelajaran berbentuk Oktagon (segi delapan) seperti instruksi desain.
- 3.2.2 Path Logic Visual:
  - Locked Octagon: Warna Charcoal redup dengan gembok neon berdenyut merah.
  - Active Octagon: Warna Electric Blue, berputar perlahan (Slow Spin Framer Motion).
  - Completed Octagon: Warna Neon Emerald, aura kemenangan hijau yang kuat.
- 3.2.3 Technical Details: Gunakan SVG untuk menggambar garis penghubung antar node. Garis ini akan mengisi warna Electric Blue secara progresif dari node yang sudah selesai ke node berikutnya menggunakan animasi stroke-dashoffset.

**3.3 Modul 2: THE QUIZ (Slang Challenge)**
- 3.3.1 Question Card: Kartu besar tipe vibe-glass. Teks soal slang menggunakan ukuran sangat besar dan bold sans-serif.
- 3.3.2 Answer Cards: Kartu pilihan jawaban berbentuk kartu neon bergaya kartu koleksi game. Saat dipilih, border-nya menyala Electric Blue.
- 3.3.3 Feedback System:
  - Correct: Layar "bersinar" Neon Emerald sekilas.
  - Wrong: Layar "glitch" Merah dan bergetar (Shake effect Framer Motion).
- 3.3.4 Power-up Button: Ikon Hint Neon di pojok yang bergetar jika user punya saldo Power-up.

**3.4 Modul 3: CHAT BUDDY (AI Interaction)**
- 3.4.1 Bubble Chat Glass: Gelembung pesan berbentuk vibe-glass dengan blur latar belakang tinggi.
  - Pesan AI: Border ungu.
  - Pesan User: Border biru.
- 3.4.2 Voice Button: Tombol mic melingkar di tengah bawah yang memancarkan aura Electric Blue yang semakin besar sesuai volume suara user.
- 3.4.3 Interaction: Gunakan AnimatePresence agar gelembung chat "slide-in" dari bawah dengan mulus.

**3.5 Modul 4: LEADERBOARD (School Rank)**
- 3.5.1 The Podium: Peringkat 1, 2, dan 3 ditampilkan dengan kartu vibe-glass yang memiliki bingkai neon logam (Emas, Perak, Perunggu).
- 3.5.2 User List: List peringkat di bawah podium menggunakan kartu transparan tipis.
- 3.5.3 Ranking Data: Ambil data realtime dari Supabase. Gunakan efek whileHover={{ scale: 1.03 }} pada setiap user di list agar terasa interaktif.

**3.6 Modul 5: MY PROFILE (Bento Dashboard)**
- 3.6.1 Bento Grid Layout: Dashboard user disusun menggunakan Bento Grid yang rapi dan profesional.
- 3.6.2 Grid Components:
  - XP Progress: Progress bar Neon Emerald yang mengisi.
  - 15-Day Streak: Ikon api neon yang berdenyut (meniru ikon api streak Duolingo tapi versi Cyberpunk).
  - Trophy Collection: Ikon trophy vector minimalis bercahaya ungu.
- 3.6.3 Responsive Layout: Pastikan bento grid ini otomatis berubah menjadi 1 kolom di layar mobile.

**3.7 Modul 6: VIBE SHOP (The Market)**
- 3.7.1 Cyber-Catalog: Katalog kartu vibe-glass untuk Power-ups. Setiap kartu memiliki ikon minimalis (Streak Freeze, Hint Neon, dsb) bergaya vector bercahaya.
- 3.7.2 Midtrans Window: Pastikan pop-up window Midtrans muncul di atas layar utama dengan latar belakang blur tinggi, menjaga nuansa Glassmorphism.
