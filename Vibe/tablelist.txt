## 2. SISTEM LEARNING PATH (KONTEN)
Struktur kurikulum utama: Course > Section > Unit > Lesson > Exercise.

- **courses** [NEW TABLE]
  - id (UUID, PK)
  - title (TEXT)
  - description (TEXT)
  - course_type (TEXT: formal/slang)
  - language_target (TEXT)

  - icon_url (TEXT)

- **sections** [NEW TABLE]
  - id (UUID, PK)

- **units** [NEW TABLE]
  - id (UUID, PK)
  - section_id (UUID, FK sections.id) [NEW FK]

  - order_index (INT)

- **lessons** [NEW TABLE]
